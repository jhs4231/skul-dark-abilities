수치 검증은 별도 계산 모델이 아니라 실행 중인 게임의 실제 Shield.Consume,
Stat, UpgradeObject와 플러그인의 회복 함수를 호출했다. 초당 회복은 명시적 시간 간격으로
진행시켰으며 실제 적과의 장시간 전투, 모든 방어막 원천의 만료 규칙,
사망·부활·모든 맵 전환 조합까지 검사한 것은 아니다.

검증 중 상점 초기화 순서, 목록 크기, 수치 점검의 Stat 갱신 순서와
개발용 저장 기능의 파일 쓰기 호출을 수정했다.
등록 목록 누락에 대비하는 상점/저장 참조 보완도 포함했다.

회복 속도 초당 5와 재생 방어막의 독립 지속은 원문에 없는 구현상 해석이다.
아이콘은 임시이며 원문 그림을 사용하지 않았다.
전체 원문 능력 중 재생 하나만 구현되어 있다.

증거 파일:

- research/final-verification.log — 최종 실행 수치 점검 통과 로그
- research/shop-save-verification.log — 실제 상점 경로와 파일 저장 로그
- research/restoration-check.json — 원본 세이브 및 설치 파일 복원/일치 확인
